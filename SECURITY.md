# Security

AO Next is experimental and has no supported release yet. The current `main`
branch receives security fixes, but it is not a production-support promise.

Report suspected vulnerabilities privately through GitHub's private
vulnerability reporting for this repository when available. Otherwise,
contact the repository owner privately through the owner's GitHub profile.
Do not open a public issue or publish proof-of-concept details before a fix is
available.

Never include credentials, provider captures, private paths, or private
campaign evidence in a report committed to this repository.
