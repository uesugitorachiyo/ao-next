# AO Mission v0.1.5 Release Notes

AO Mission `v0.1.5` is a compatibility patch release.

## Included Fixes

- Carry the integrated Windows compatibility fixes through the Mission CI,
  native-artifact, and default-environment gates.
- Preserve read-only lifecycle ownership and existing authority restrictions.

No provider calls, deployments, publications, merges, or compatibility
activation are introduced by Mission.
